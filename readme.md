# You can cry about it or you can just start solving your problems

## Overview
This repository contains solutions to LeetCode problems, organized by topic and difficulty level. Each solution includes detailed explanations, intuition, approach analysis, and complexity breakdowns.

## Project Structure
The solutions are organized in the following categories:

- **Arrays & Hashing** - Basic array operations, hash maps, and set operations
- **Two Pointers** - Pointer manipulation techniques for efficient solutions
- **Sliding Window** - Window-based optimization for subarray/substring problems
- **Stack** - Stack data structure applications
- **Binary Search** - Search optimization and rotated array problems
- **Linked List** - Node manipulation and list traversal
- **Trees** - Binary trees, BSTs, and tree traversal algorithms
- **Tries** - Prefix trees for string problems
- **Heap** - Priority queue and heap sort applications
- **Graphs** - Graph traversal, shortest path, and connectivity problems
- **Advanced Graphs** - Dijkstra's algorithm, MST, topological sort
- **Backtracking** - Recursive exploration and combination problems
- **Dynamic Programming 1D** - Simple recurrence relations and optimization
- **Dynamic Programming 2D** - Matrix and complex recurrence problems
- **Greedy** - Greedy algorithm design and proof strategies
- **Intervals** - Interval merging and scheduling problems
- **Bit Manipulation** - Bitwise operations and optimization techniques
- **Math & Geometry** - Mathematical operations and geometric calculations

## Getting Started

### Prerequisites
- Java 8 or higher
- Maven 3.6 or higher

### Building the Project
```bash
mvn clean compile
```

### Running Solutions
To test a specific solution, uncomment the examples in the `main` method of the respective class and run:
```bash
mvn exec:java -Dexec.mainClass="org.example.arrays.P1TwoSum"
```
